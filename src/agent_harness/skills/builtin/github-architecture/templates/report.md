## Tổng quan
Mục đích của repo, ngôn ngữ, cách chạy. [E#]

## Cấu trúc thư mục
Các package/module chính và trách nhiệm của từng phần. [E#]

## Quan hệ phụ thuộc
Module nào dùng module nào (theo đồ thị phụ thuộc), module trung tâm (fan-in cao), vòng phụ thuộc nếu có. [E#]

## Luồng thực thi chính
1. Entrypoint → ... (file:dòng) [E#]
2. ...

## Thư viện ngoài
Thư viện quan trọng và vai trò. [E#]

## Nhận định của agent
Điểm mạnh, điểm cần lưu ý, gợi ý đọc tiếp. (Phần này là suy luận, không phải nội dung repo.)

## Phạm vi đã đọc
Kết quả `github_coverage`: số file/dòng đã đọc trên tổng, các file quan trọng chưa đọc.
